# IERB Website Project Repository

Welcome to the official GitHub repository for the **Institut Évangélique Réformé de Bukavu (IERB)** website project. This project is developed by **FREEDEV**.

---

## Project Overview

The purpose of this project is to develop a professional, accessible digital platform for the Institut Évangélique Réformé de Bukavu. The website serves as a centralized hub to communicate the Institute's identity, biblical and theological training programs, courses, events, resources, and announcements to current students, prospective participants, churches, and the general public.

- **Organization:** Institut Évangélique Réformé de Bukavu (IERB)

- **Project Type:** Biblical, Theological & Educational Institution Website

- **Prepared By:** FREEDEV

- **Project Lead / Mentor:** Philemon B.

- **Team Members:** Paul, Efatha and Prince

- **Estimated Duration:** 5 Weeks

- **Status:** Draft, Pending Stakeholder Review

---

## Proposed Website Structure

The website is structured to cover all necessary institutional, academic, and administrative requirements:

1. **Home**

2. **About the Institute** (Overview, History, Mission, Vision, Doctrinal Statement)

3. **Programs** (Degree/Certificate programs, objectives, audience, duration)

4. **Courses / Training** (Course titles, descriptions, schedules, instructors)

5. **Admissions / Registration** (Requirements, process, forms)

6. **Academic Information** (Calendar, methodology, policies)

7. **Faculty & Leadership**

8. **Events** (Seminars, conferences, workshops)

9. **News / Articles**

10. **Biblical & Theological Resources** (Study materials, articles, documents)

11. **Students / Student Life**

12. **Alumni / Community**

13. **Gallery**

14. **Support / Giving**

15. **Contact** (Address, map, phone, email, social links)
